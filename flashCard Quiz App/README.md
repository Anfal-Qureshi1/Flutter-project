# Flashcard Quiz App

A simple Flutter learning app for creating and reviewing question-and-answer flashcards.

## Current features

- Flip a card to reveal its answer
- Navigate to previous/next cards
- Add a flashcard
- Edit a flashcard
- Delete a flashcard
- Material 3 styling

The app uses the `flip_card` package for the card animation.

## Run

```bash
flutter pub get
flutter run
```

## Note

Flashcards are stored in memory in the current version. Changes are lost when the app is restarted.
